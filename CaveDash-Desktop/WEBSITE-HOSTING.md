# Hosting the Cave Dash download website

The `website/index.html` file is a static download page. To publish it, upload its contents to a static host such as GitHub Pages or Netlify. Put `CaveDash-Desktop-Source.zip` in the location referenced by the page, or edit the links to point at the final installer files you publish.

The project bundle does not contain precompiled `.exe` or `.dmg` installers. Those should be generated on their respective operating systems with the scripts in `README.md`, then uploaded to your site.
