# Cave Dash download page

This is a static download page. Upload the `website` folder to any static web host (GitHub Pages, Netlify, or your own web server). Keep `CaveDash-Desktop-Source.zip` at the parent/root path expected by the download link, or update the hrefs to match your hosting layout.

The current buttons link to the source/build-kit ZIP, not a precompiled installer. Build Windows and macOS installers using the instructions in the project README first, then update the website buttons to link to those installer files.
